Mush Track Snowbank - Low Poly (Original Size / Exaggerated Side Facets)

레퍼런스 이미지(01_Track_and_Snowbank.png) 하단의 눈 둑을 기준으로 제작한 독립형 3D 에셋입니다.
최초 버전의 전체 크기와 낮고 연속적인 실루엣을 유지하면서, 측면에만 국소적인 돌출과 높이 편차를 추가해 울퉁불퉁한 삼각 면이 더 잘 보이도록 조정했습니다.

구성 파일
- Mush_Track_Snowbank_LowPoly.blend : 편집 가능한 Blender 원본
- Mush_Track_Snowbank_LowPoly.fbx   : Unity 임포트용 권장 파일
- Mush_Track_Snowbank_LowPoly.obj/.mtl : 범용 교환 파일
- Mush_Track_Snowbank_LowPoly_Preview.png : 렌더 미리보기
- Mush_Track_Snowbank_LowPoly_Manifest.json : 에셋 정보
- Mush_Track_Snowbank_LowPoly_Validation.json : FBX 검증 결과
- create_lowpoly_snowbank.py : 메시 재생성용 Blender Python 소스

사양
- 크기: 약 12.0 x 2.67 x 2.03 m
- 피벗: 월드 원점, 바닥 Z=0
- 스타일: 삼각 분할/플랫 셰이딩 로우폴리 눈, 강조된 측면 요철
- FBX: 단일 메시, 321 버텍스, 638 트라이앵글
- 머티리얼: Snow_Matte_White 1개
- 검증: 닫힌 메시, 오류 없음
