TrackTest 장애물 회피 테스트

시작
- Track_v2_TrackTest.unity를 열고 Unity Play를 누릅니다.
- Game 창을 클릭한 뒤 Space로 출발합니다. A/D 조향, W 가속 유지, P 마우스 시점 전환.
- F8: 회피 및 최소 관통 방지를 함께 켜거나 끕니다. OFF에서는 장애물을 통과할 수 있습니다.
- F9: 출발 이후 약 24/58/92m 지점의 데모 장애물 3개를 켜거나 끕니다.
- F10: 출발 위치로 돌아갑니다. 주행 중이었다면 기본 속도로 다시 움직입니다.
- 완주 저장을 피하려고 경로 진행률 96%에서 자동으로 출발 위치로 돌아갑니다.

구성
- 원본 Track_v2의 저장된 씬을 복사했습니다. 원본 씬과 프리팹은 편집하지 않습니다.
- 씬의 직접 참조 프리팹과 Track_v2_AuthoringAssets 메시 데이터를 이 폴더로 복사했습니다.
- 원본 테스트의 추종/마우스 시점 스크립트는 별도 namespace를 가진 복사본으로 교체했습니다.
- 재질, 텍스처, FBX, 애니메이션, 조명 데이터와 기본 주행 코드는 기존 자산을 읽기 전용으로 참조합니다.
- 이 테스트에서 편집할 프리팹은 Prefabs 안의 복사본만 사용합니다.
- Build Settings와 프로젝트 물리 설정은 변경하지 않았습니다. 에디터 테스트용 씬입니다.

회피
- 대상: Tree01/Tree02, Rock01/Rock02/Rock03의 기존 배치와 데모 배치.
- 복사 프리팹에는 CapsuleCollider(Is Trigger)와 TrackTestObstacle만 추가합니다.
- Rigidbody, OnTrigger 콜백, 장애물별 Update는 사용하지 않습니다.
- Ignore Raycast 레이어(2)를 명시적으로 검색하되 TrackTestObstacle이 있는 판정만 사용합니다.
- 팀 중심의 주행 루트에 추가 회전을 주며, 기존 플레이어 조향은 유지합니다.
- 몸체 반경에 팀 반폭과 0.6m 여유를 더한 큰 인식 범위를 계산합니다.
- 속도에 비례한 전방 거리, 거리/방향별 회전, 같은 장애물을 완전히 지날 때까지 좌우 선택 유지, 원래 방향 복귀를 적용합니다.
- 가까운 장애물은 SphereCast로 팀과 썰매 이동을 각각 제한합니다.
- 회피는 경로 탐색 AI가 아닙니다. 막힌 틈, 정면으로 계속 미는 입력, 판정 안에서 출발하는 상황은 별도 확인이 필요합니다.

조정
- Hierarchy의 Mush Ride Team을 선택하고 Track Test Avoidance 컴포넌트를 조정합니다.
- 팀 반폭: 1.25m / 바깥 회피 여유: 0.6m / 앞을 보는 시간: 1.1초 / 최소 전방 거리: 6m.
- 추가 회전 속도 상한: 42도/초 / 방향 편차 상한: 24도 / 원래 방향 복귀: 0.8초.
- 나무 판정은 잎 전체 대신 줄기를 근사합니다. 바위는 몸체의 수평 폭을 근사합니다.
- Scene 뷰에서 Gizmos를 켜고 팀을 선택하면 전방 인식과 현재 대상의 여유 반경을 볼 수 있습니다.
- 개별 장애물을 선택하면 몸체 판정을 확인할 수 있습니다.

검증할 상황
- Space 출발 후 조향 없이 첫 데모 나무를 빗겨가는지 확인합니다.
- F10으로 돌아와 W 가속 상태에서도 충분히 일찍 반응하는지 비교합니다.
- F8 OFF/ON, F9 OFF/ON을 비교합니다.
- 연속 장애물, 도로 가장자리, 반대 조향, 썰매 뒷부분의 통과, 급격한 프레임 저하를 확인합니다.
- VR에서는 자동 회전이 편안한지와 플레이어의 조향 권한이 충분한지 직접 확인합니다.

성능
- 주변 검색 20Hz, 재사용 버퍼 128개, 회전/이동 보정은 매 프레임입니다.
- Profiler의 TrackTest.ObstacleAvoidance 마커로 추가 비용을 확인할 수 있습니다.
- 화면의 us/call은 에디터의 각 호출 표본을 평활한 참고치이며 전체 프레임 비용이나 Quest 측정값이 아닙니다.
- 성능 측정 때는 Show Diagnostics와 Scene Gizmos를 끄고 같은 구간의 F8 OFF/ON을 비교합니다.

자동 검증 결과
- 컴파일 및 씬 연결 검증 통과. 프리팹 인스턴스 1,434개 모두 이 폴더의 복사 프리팹을 사용합니다.
- 첫 데모 나무에서 OFF는 관통, 일반 ON과 가속 ON은 안전 보정 없이 회전으로 통과했습니다.
- 팀의 최소 판정 여유: 일반 ON 약 0.67m, 가속 ON 약 0.80m. 썰매도 각각 약 1.07m, 1.16m 여유를 확보했습니다.
- 이는 6초씩 진행한 첫 장애물 검증입니다. 전체 코스와 VR 기기 검증을 의미하지 않습니다.
- 테스트 중 새 Unity 오류 없음. 게임 저장 파일과 백업의 해시도 유지됐습니다.
- 세부 조건, 측정 수치, 검증 한계는 ValidationReport.json을 확인합니다.

게임 저장
- 복사 씬의 MushSceneUI를 비활성화하여 기본 시작/주기 자동 저장을 끕니다.
- 체력 소모는 0, 제한 시간은 24시간, 완주 직전에는 시작 지점으로 돌아오도록 설정했습니다.
- 일반 게임의 옵션/일시정지/완주 화면 검증은 이 테스트의 범위에 포함하지 않습니다.

범위
- 이번 테스트에 한해 프로젝트 내부 복사 및 복사 씬 작업에 대한 사용자 예외 승인을 받았습니다.
- 작성/수정한 소스 자산은 Assets/Test/TrackTest와 폴더의 필수 .meta에 한정합니다.
- 이 폴더를 제거하면 테스트 스크립트, 복사 씬, 복사 프리팹을 함께 제거할 수 있습니다.
