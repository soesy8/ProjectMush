# 씬 편집

- 씬은 `Assets/Mush/Scenes`, 공용 코드는 `Runtime`의 `Ride`, `Tracks`, `VR`, `Environment`, `UI`에 있습니다. 로비·상점·꾸미기는 각각 `Lobby`, `Store`, `Customization`에 있습니다.
- 주행 씬의 `Mush Ride Team` 아래 `Dog 01` 등의 오브젝트를 복제하거나, 모델을 넣은 부모에 `Mush Ride Dog` 컴포넌트를 추가합니다. `Visual`에 모델을 연결합니다. 플레이 시작 시 활성화된 팀원을 수집하므로 두 마리 제한이 없습니다.
- 개의 배치와 크기는 씬에서 편집합니다. `Customization Index`는 저장 장비 번호이며, `-1`이면 씬에 배치한 장식을 사용합니다. 기존 개는 0, 1이고 추가 개는 서로 다른 번호를 지정할 수 있습니다. 상점의 개 선택 UI는 현재 기존 두 마리용입니다.
- 두 손의 고삐 연결점은 팀원 수와 별개입니다. 추가 개의 줄은 `Tow From`, `Harness`, `Tow Line`으로 연결할 수 있습니다.
- `MAP EDITOR`에서 도로 포인트, 모델, 폭을 편집합니다. 지형 모델을 직접 이동한 뒤에는 `도로 갱신 · 씬에 저장할 형태로 적용`을 누르고 씬을 저장합니다.
- 도로 모델은 로컬 Z축을 길이 방향으로 사용합니다. 곡선 메시를 편집 단계에서 구간별로 생성하며, 전체 생성 정점은 240,000개로 제한됩니다. 원본 모델이 복잡하면 단순한 모델이나 기본 도로를 사용합니다. 메시 예산은 VR 프레임 성능 보증값이 아닙니다.
- 도로·지형 메시와 경로는 씬 저장 시 함께 저장합니다. 플레이에서는 저장된 메시를 사용하며 지형과 도로를 다시 생성하지 않습니다. `GeneratedMaps`는 이 저장 데이터입니다.
- 일반 모델과 오브젝트는 씬에 직접 배치합니다. 자동 생성된 도로의 형상을 수정하려면 포인트나 원본 모델을 편집합니다. 하늘·날씨·주행 애니메이션과 저장 장비 적용은 플레이 중에도 동작합니다.

Unity 6 컴파일과 세 주행 씬 변환은 완료했습니다. 마지막 수정에 대한 추가 실행 검증은 요청에 따라 생략했습니다. 실제 헤드셋의 양안 표시·입력·프레임 성능은 직접 확인이 필요합니다.
